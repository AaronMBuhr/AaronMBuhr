## Selected projects

### [Involvant Signal](https://aaronbuhr.com/#signal)
A civic information platform that brings public meetings and agenda documents together from official sources. Uses LLM-generated, inspectable parser specifications with deterministic extraction and persistence. The public case study covers source discovery, browser automation, run tracking, and deployment; the source repository is private.

**C# · ASP.NET Core · EF Core · PostgreSQL · Playwright**

### [MailLens](https://github.com/AaronMBuhr/maillens)
Self-hosted search and question answering over Thunderbird email archives. Combines vector and keyword retrieval, conversation context, source citations, and streaming responses. Supports local embeddings and a choice of local or hosted language models.

**Python · FastAPI · PostgreSQL / pgvector · React · Docker**

### [AI Command Reviewer](https://github.com/AaronMBuhr/ai-command-reviewer)
Reviews proposed shell commands before an AI coding agent executes them. Combines configurable policy checks with model-based review, with adapters for multiple coding agents and tests for the review pipeline. It assists command review; it isn't an execution sandbox.

**Python · Agent hooks · Policy checks · LLM integration**

### [AI MCP Server](https://github.com/AaronMBuhr/Ai-mcp-server)
A reusable service for rendering prompt templates and routing requests to configured model providers. Keeps application workflows separate from provider integration, with request validation and automated tests.

**Python · Model Context Protocol · Prompt contracts · Provider routing**

### [NextGenMUD](https://github.com/AaronMBuhr/NextGenMUD)
A text-based multiplayer game engine built with Django and WebSockets. Includes YAML-defined worlds, commands, combat, and event-driven scripting. An ongoing development project that brings together my interest in online worlds and backend systems.

**Python · Django Channels · WebSockets · Game-state management**
